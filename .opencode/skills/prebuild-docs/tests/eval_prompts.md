# 触发测试提示集

使用这些提示测试本 skill 是否能在合适场景下触发，并避免误触发。

## 应该触发

- 帮我根据这个项目生成一套 `AGENTS.md`、`CURRENT_STATE.md`、`FRONTEND_DESIGN.md` 和 `docs/plans/` 文档。
- 这个项目已经有 demo 了，帮我沉淀一套后续 coding agent 能快速接手的上下文文档。
- 我准备正式开发这个项目，帮我先搭一套低噪音的工程文档体系。
- 帮我重构现在混乱的项目文档，把当前事实、历史方案、前端设计规范分开。
- 根据 README 和代码结构，为这个仓库生成标准的 agent 接手文档。
- 帮我为这个 repo 创建一套可维护的 agent skill / coding agent 上下文文档。

## 不应该触发

- 帮我写一篇项目介绍文案。
- 帮我写 changelog。
- 这个 bug 怎么修？
- 帮我把 README 润色一下。
- 帮我记录今天做了哪些修改。
- 帮我解释一下这个前端组件为什么报错。
