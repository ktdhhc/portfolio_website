# 项目信息提取清单

在生成文档体系前，先使用本清单提取项目事实。

## 项目成熟度

先判断项目类型：

```text
A. 方案刚确定，代码很少或尚未开发
B. 已有一版可运行 demo 或原型
```

## 仓库事实

优先查找：

- 项目名称和一句话目标
- 当前阶段
- 范围边界
- 前端和后端目录
- 主入口文件
- 路由文件
- service 文件
- 数据库或存储层
- worker、队列或异步任务逻辑
- 状态名称
- canonical payload 结构
- 测试文件
- 脚本和运行命令
- 默认验证命令

## 前端事实

优先查找：

- 当前页面
- 核心用户流程
- 可复用组件
- 视觉基调
- 布局模式
- 状态标识
- 表格和表单行为
- 错误态与空态
- 响应式行为
- 动效约定

## 方案材料

优先查找：

- 初始实现方案
- feature 设计说明
- 架构选择依据
- 重大取舍
- 后续 workflow 提案

## 信息缺失时

不要发明未知事实。

可以使用以下占位符：

```text
<pending>
<repo-root>
<backend-dir>
<frontend-dir>
<current-stage>
<main-entry-file>
<run-command>
<test-command>
```
