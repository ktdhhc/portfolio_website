•行业地位：中国领军的兴趣社交与AI科技企业，连续入选“中国互联网百强”及“2025福布斯中国人工智能科技企业TOP 50”。
•核心产品：
￮TT语音：国内最大的移动游戏社交平台之一，累计注册用户超2亿，拥有海量的多模态社交数据与高活跃的Z世代用户场景。

2. 背景与动机
1.1 当前现状：行为理解的“高分低能”
随着大语言模型（LLM）的飞速发展，诸多研究表明，在预设的静态文本情景下，LLM 对行为的判断和决策能力已展现出惊人的潜力，甚至超过了普通人类的平均水平，但在许多角色扮演的场景中其认知理解能力与行为决策往往出现错配，即“猜错了但做对了”。
1.2 核心痛点：评测范式的错位
尽管模型越来越“懂”语言，但当前的评测体系存在滞后 ：
•评测形式局限：绝大多数依赖问答形式，测试的是信息检索和语言组织能力。
•行动维度缺失：缺乏对复杂动态环境下决策与行动能力的考察；现有的轨迹理解评测仍停留在让模型“回答”而非“经历”人生。
1.3 我们的愿景
我们致力于推动 AI 研究从 “懂你” 走向 “像你一样行动” ：
•弥合鸿沟：建立首个评估 LLM 将情境理解转化为具体行动能力的基准。
•重新定义“类人”：将标准从“能说会道”提升到 “行事合理”。

2. 核心理念：PersonaAct
2.1 角色重构：从旁观者到主角
LLM 不再是旁观者，而是作为 主角，以第一人称视角亲身 “经历” 一段完整的人生轨迹 。
2.2 评测核心："Deeds, not Words"
"A man is judged by his deeds, not by his words." 我们重点考察 LLM 在面临关键的 决策岔路口 时，能否做出符合其特定人格设定的实际行动 。

3. 理论骨架：S-O-R 认知模型
我们将 Agent 的交互过程抽象为经典的心理学模型，并结合双系统理论进行细化：
3.1 基础架构
•S (Stimulus) - 外部线索：来自外部环境的输入（人物互动、事件、背景）。
•O (Organism) - 心理加工机制：Agent 内部的“黑盒” 。
￮目前构想（待研讨）：我们倾向于将此环节视为基于 System 1 (直觉/快思考) 和 System 2 (理性/慢思考) 综合后的价值判断结果。该判断包含了态度变化、情绪感知或潜台词分析，直接导向随后的行为决策 。
•R (Response) - 行为决策：最终外显的具体行动或对话 。
3.2 变量定义
•人格特质 (Variable A)：沿用 大五人格 作为 Agent 的“出厂设置”，维持长期一致性 。
•心理中介变量 (Variable B)：即“O”的具体内容，目前候选理论包括 心理情境理论 (DIAMONDS) 和 态度理论 ，需与专家共同确定最佳落地方案 。

4. 数据构建策略：模拟生成与专家筛选
为了兼顾数据的多样性（AI 擅长）和准确性（专家擅长），我们提出一套 “机器海选 -> 专家精选”  的构建工作流 。
4.1 资产定义：标准化的“考场”与“考生”
•世界线 (Worldlines)：选定 N 个具有强规则、高辨识度的世界（如末日生存、古代宫廷、赛博朋克），包含完整的世界观文档和关键事件节点 。
•经典角色 (Characters)：
￮人格设定和量化：挑选具有鲜明人格特点的经典角色，并采用大五人格量表去定量测量其人格特点。
￮记忆初始化：为每个角色构建详细的过往经历摘要，并初始化长时情境记忆，存入记忆系统，确保 Agent 在进入测试前具备完整的“人生前史” 。
4.2 轨迹重构与并行采样
•客串逻辑：将角色 Agent 放入与其原设不同的世界线情节中进行“客串” 。
•K-Sample 并行采样：
￮针对同一个情节，让 Agent 重复运行 K 次（如 K=5 或 10）。
￮每次运行均要求 Agent 并行输出 O (内部心理状态) 和 R (外显行为)，生成 K 组完全不同的 State + Action 候选样本。
4.3 黄金标准 (Ground Truth) 确立机制
•多专家评分：向专家展示情节、人设及 K 个候选样本。专家基于 “人设一致性” 和 “逻辑必然性” 对样本进行打分。
•GT 产出路径：
a.若 K 个样本中有高质量结果，直接选取得分最高的一组作为 Ground Truth 。
b.若 K 个样本均未达标，由专家进行手动改写/修正，确保数据的黄金标准 。
4.4 干扰项与测试题构建
•干扰项设计：针对每个 GT，编写 2-3 个干扰选项。要求干扰项逻辑通顺，但不符合该角色在当下的极致人设（如符合普通人反应或相反人格反应）。
•扩展性：数据结构预留 DPO 接口，支持未来对模型的对齐训练 。

5. 实验设计：世界线与客串
5.1 实验逻辑：世界线矩阵
•客串机制：选取强人格 Agent “客串”到陌生世界线 。
•验证标准：
￮人格一致性：考察 Agent 在陌生环境下是否依然做出符合其原有人格特质的选择 。
￮认知-行为一致性：Agent 报告的心理指标（O）与其行为选择（R）是否逻辑自洽 。
5.2 开放式评测扩展
引入 LLM-as-a-Judge，对 Agent 的自由生成内容进行“人格神似度”和“行为逻辑”的对比打分。

6. 专家研讨核心议题 (Key Discussion Points)
结合工作流中的待定事项，我们诚挚邀请各位专家针对以下问题提供指导：
1.心理加工机制 (Organism) 的定义：
￮在 S-O-R 框架中，我们目前设想的 “System 1 + System 2 的综合价值判断” 模式是否合理？
￮应使用 DIAMONDS 还是 态度理论 来具体量化这一过程？
2.角色设定的验证：
￮如何确立角色的初始设定细节更为合理？
￮对 Role-Play Agent 进行前置人格测量是否应该使用大五人格量表，还是有其他效度更高的方法？
3.GT 筛选标准的阈值：
￮如何定义“选项同质化”的标准？多大程度上类似的选项需要被剔除？
￮在“多专家评分”环节，如何定义“分数低”和“分数高”的界限？在何种一致性水平下（如 3/5 专家同意）我们才采纳 AI 生成的样本，而非人工重写？
4.数据集的质量保证：
￮数据集构建完成后是否需要先对人类被试进行施测来确保题目具有恰当的区分度？
