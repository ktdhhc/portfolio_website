# 角色记忆抽取流程设计

## 主链流程

1. **文本预处理**：清洗原文、分段、标注角色名
2. **人生节点抽取**：识别角色的人生关键事件
3. **事件扩展**：补充事件的上下文、时间、地点、情感
4. **术语映射**：将原文术语映射到统一概念
5. **第一人称记忆转换**：将第三人称叙述转为角色视角的记忆
6. **最终检查**：人工审核 + 一致性校验

## 人格分析分支

- 人格画像合成：从行为描述推断人格特征
- 候选情境筛选：根据人格匹配可能的情境
- 草案生成：LLM 生成情境反应草案
- 人工审核：确认或修正草案

## 幻觉控制策略

- 分步抽取而非一次性生成，每步可审核
- 术语映射约束 LLM 的表达范围
- 第一人称转换保留原文事实，不生成新信息
- 日志追踪每步的输入输出，可回溯
