# Aindexer 技术架构详解

## 整体架构

Aindexer 采用本地化应用架构，前端基于 React，后端基于 FastAPI，数据存储使用 SQLite + 本地文件系统。

## 核心模块

### 文献上传与解析
- 支持 PDF 等格式的文献上传
- 解析后提取元数据（标题、作者、摘要、发表时间）
- 结构化存储到 SQLite

### 结构化索引
- 对文献内容进行语义分块
- 构建 Embedding 索引支持语义检索
- 支持字段模板自定义索引维度

### 搜索预览
- 基于向量检索的语义搜索
- 返回匹配片段及上下文
- 支持高亮和快速定位

### 翻译工作流
- 支持文献片段翻译
- 人工修订界面
- 术语库管理

### Workspace 管理
- 多项目管理
- 字段模板复用
- 导入导出备份

## 技术选型理由

- FastAPI：轻量、异步、自动文档
- SQLite：零配置、本地化、足够性能
- React：组件化、生态成熟
- RAG：语义检索的核心能力
