# Aindexer 版本迭代记录

## V1 — 基础文献管理

- 文献上传与元数据提取
- 基础搜索功能
- SQLite 存储

## V2 — 结构化索引与翻译

- 引入 RAG 语义检索
- 字段模板机制
- 翻译工作流
- Workspace 多项目管理

## V3 — 体验优化与发布

- 搜索预览优化
- 导入导出备份
- 发布至 GitHub 和产品主页
- AI Coding 工具深度集成辅助开发

## 用户反馈与改进方向

- 检索精度持续优化
- 多格式文献支持扩展
- 协作场景探索
