# 认知科学到 Agent 架构的映射

## 记忆模型映射

- **工作记忆** → Agent 的短期上下文窗口
- **情景记忆** → Agent 的 episodic memory 存储
- **语义记忆** → Agent 的知识库 / RAG 检索

## 内部状态模拟

- 认知科学的"内部状态"概念 → Agent 的情绪理解和行为输出
- 内部状态不是显式情绪标签，而是影响行为倾向的隐变量

## 任务规划

- **双系统理论**（System 1 / System 2）→ Agent 的快速响应 vs 深度推理
- **启发式偏差** → Agent 在有限信息下的决策策略

## 情绪理解

- 情绪不是独立模块，而是嵌入在记忆、状态和行为中的维度
- 基于认知评估理论设计情绪对行为输出的影响路径
