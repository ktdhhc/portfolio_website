## 项目背景

在趣丸科技的社交产品实习中，围绕认知科学驱动的 AI 产品研发，参与 Agent 原型的设计与迭代。核心任务是将心理学、认知神经科学的理论转化为可落地的产品功能模块。

## 解决的问题

Agent 产品的记忆机制、内部状态模拟、任务规划等模块缺乏理论支撑，容易出现"工程能跑但行为不合理"的问题。需要系统梳理认知科学文献，为架构设计提供依据。

## 我的职责

梳理心理学、认知神经科学、人类决策、记忆机制与心理表征等相关文献，为 Agent 架构设计提供理论依据。参与 Agent 架构设计讨论，围绕记忆机制、内部状态模拟、任务规划、情绪理解和行为输出等模块提出优化建议。跟进 Agent 原型多轮迭代，协助将认知科学理论转化为可实现的产品功能模块。

## 核心设计

围绕认知科学的记忆模型（工作记忆、情景记忆、语义记忆）设计 Agent 的记忆架构。将认知科学中的"内部状态"概念映射到 Agent 的情绪理解和行为输出模块。基于人类决策理论（双系统理论、启发式偏差）设计 Agent 的任务规划逻辑。

## 技术或工具

文献综述 + Agent 架构设计讨论 + 原型迭代跟进。

## 产出结果

为 Agent 架构设计提供了系统的认知科学理论依据。参与了多轮原型迭代，协助将理论转化为可实现的产品功能模块。优化建议覆盖记忆机制、内部状态模拟、任务规划、情绪理解和行为输出等核心模块。
