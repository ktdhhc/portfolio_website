# 记忆系统测试方法论

## 测试流程

1. **测试调用**：按测试集规范发起 Agent 对话
2. **记忆检索**：检查 Agent 是否正确召回相关记忆
3. **召回检查**：对比召回内容与预期答案
4. **回答评分**：按维度打分（准确性、完整性、一致性）
5. **错题分析**：对低分回答进行根因分析

## 四类问题来源

### 记忆召回
- Agent 未召回应召回的记忆
- 召回了错误或不相关的记忆
- 召回内容不完整

### 信息整合
- 召回了正确记忆但未能整合到回答中
- 多条记忆整合时出现矛盾
- 整合结果偏离原始语义

### 角色一致性
- 回答风格与角色人设不符
- 角色特征在多轮对话中漂移
- 角色记忆与角色行为不匹配

### 回答生成
- 记忆正确但表达不当
- 语言风格不稳定
- 出现幻觉（编造未提供的信息）

## 评分维度

- 准确性：回答是否符合事实
- 完整性：回答是否覆盖关键信息
- 一致性：回答是否与角色人设一致
- 流畅性：回答是否自然可读
