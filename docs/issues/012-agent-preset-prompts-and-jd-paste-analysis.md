## What to build

这是阶段 2 的第三个 tracer bullet，补上访客最容易直接使用的高价值入口。

**预设问题按钮**：在 `/agent` 页面提供一组可直接点击的预设问题，至少覆盖：自我介绍、项目问答、岗位匹配、优势不足、面试问题。点击后应触发一次真实提问，而不是只填充输入框不发送。

**JD 粘贴分析**：在 `/agent` 页面提供独立的 JD 文本域与“分析”按钮。该能力不是独立 API，而是复用 `POST /api/chat`：前端负责把引导语与 JD 文本拼成一次普通提问。

**边界保持一致**：JD 粘贴分析仍然受 answer-rules 约束，只能基于现有资料分析匹配点、风险点和建议追问；不能把它做成自动筛选器、岗位打分器或招聘自动化流程。

## Acceptance criteria

- [ ] `/agent` 页面包含预设问题按钮：自我介绍、项目问答、岗位匹配、优势不足、面试问题
- [ ] 点击任一预设问题按钮会触发一次真实提问并出现回答
- [ ] `/agent` 页面包含 JD 粘贴文本域和“分析”按钮
- [ ] JD 粘贴分析复用 `POST /api/chat`，不新增独立 API
- [ ] 粘贴 JD 并点击分析后，Agent 能基于现有资料输出匹配点、风险点和建议追问
- [ ] JD 粘贴分析不输出脱离资料的打分、承诺或自动筛选结论
- [ ] E2E / 集成测试覆盖：预设问题点击有效 + JD 粘贴分析有效
- [ ] `npm run build` 成功
