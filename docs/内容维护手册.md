# 内容维护手册

这份手册只回答 3 件事：**改哪里、怎么改、改完怎么验**。

## 1. 改资料时看哪里

| 你要改什么 | 改哪个文件 |
|---|---|
| 姓名、简介、联系方式、GitHub、主页 | `content/profile.json` |
| 教育、实习/工作、技能 | `content/resume.json` |
| 项目卡片信息 | `content/projects/<slug>/index.md` 的 frontmatter |
| 项目详情正文 | `content/projects/<slug>/index.md` 的正文 |
| 给 Agent 的补充资料 | `content/projects/<slug>/refs/*.md` |
| 公开图片 / 示意图 | `public/images/...` |
| PDF 简历 | `public/resume.pdf` |

---

## 2. 每种资料怎么改

### 2.1 基础信息：`content/profile.json`

适合放：首页 Hero、Footer、联系方式。

常改字段：
- `name`
- `tagline`
- `description`
- `email`
- `github`
- `homepage`

---

### 2.2 简历主体：`content/resume.json`

分三块：
- `education`
- `experience`
- `skills`

注意：
- `skills` 里 `highlight: true` 表示高亮技能
- `experience.projects` 是该段经历下的子项目说明

---

### 2.3 项目：`content/projects/<slug>/index.md`

一个项目一个目录。

文件结构：

```text
content/projects/<slug>/
  index.md
  refs/
    *.md
```

`index.md` 分两部分：

#### A. frontmatter（项目卡片信息）

必填字段：

```yaml
---
name: 项目名
tagline: 一句话说明
type: personal | internship
company: 公司名            # 仅 internship 必填
role: 你的角色
period: 时间
tags:
  - 标签1
  - 标签2
links:
  github: https://...
  demo: https://...
  docs: https://...
featured: true | false
---
```

规则：
- `type=internship` 时必须写 `company`
- 首页只展示 `featured: true` 的项目

#### B. 正文（项目详情页内容）

建议保持这 9 段：
1. 项目背景
2. 解决的问题
3. 我的职责
4. 核心设计
5. 技术或工具
6. 产出结果
7. 难点与复盘
8. 可验证材料
9. 可追问问题

---

### 2.4 Agent 补充资料：`refs/*.md`

这些文件**不给公开页面用**，只给 Agent 读。

每个文件都要有：

```yaml
---
summary: 一句话摘要
---
```

适合放：
- 更细的架构说明
- 迭代记录
- 测试方法
- 背景补充

---

## 3. 图片 / 示意图怎么放

### 公开展示的图片

放到：`public/images/...`

推荐结构：

```text
public/images/projects/aindexer/architecture.png
public/images/projects/aindexer/workflow.png
```

在 `index.md` 里这样写：

```md
![Aindexer 架构图](/images/projects/aindexer/architecture.png)
```

如果想更可控，也可以直接写 HTML：

```html
<img src="/images/projects/aindexer/architecture.png" alt="Aindexer 架构图" style="max-width: 100%; border-radius: 12px;" />
```

### 重要边界

- 放进 `public/` 的图片就是**公开可访问**的
- 如果某张图只想给 Agent 看，当前版本**不要放图片**，改成文字写进 `refs/*.md`

---

## 4. 新增一个项目的最小步骤

1. 新建目录：`content/projects/<slug>/`
2. 新建 `index.md`
3. 写 frontmatter
4. 写 9 段正文
5. 如果要给首页展示，设 `featured: true`
6. 如果要给 Agent 补资料，再新建 `refs/*.md`

---

## 5. PDF 说明

- 真正的 PDF 文件路径：`public/resume.pdf`
- 如果这个文件不存在，页面会自动显示“**PDF 简历待补充**”，不会报错
- 所以：**想启用下载，就把文件放进去；不放也没关系，只是不会提供下载**

---

## 6. 改完后怎么验证

### 只改文字 / JSON / Markdown

```bash
npm run build
```

### 改了项目 frontmatter / refs / schema 相关内容

```bash
npm run build
npm run test:schema
```

### 改了页面展示、图片、导航、交互

```bash
npm run build
npm test
```

### 要确认性能验收

```bash
npm run test:lighthouse
```

---

## 7. 最常用的判断规则

- 想改**人**的信息 → `profile.json`
- 想改**简历** → `resume.json`
- 想改**项目卡片/详情** → `projects/<slug>/index.md`
- 想加**Agent 私有补充** → `projects/<slug>/refs/*.md`
- 想放**公开图片** → `public/images/...`
- 想启用 **PDF 下载** → `public/resume.pdf`
